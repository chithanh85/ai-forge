## Generated documentation

`DEBT_LEDGER.md` and `debt_ledger.json` are generated by `scripts/maintenance/debt_scanner.py`. Do not hand-edit generated totals; regenerate them after changing debt markers.

## Historical records

These directories are evidence of how the template evolved, not current instructions:

- `plans/completed/`
- `wiki/lessons/`

Historical documents may retain old terminology when that matters to the record, but should point readers back to the current contract.

## Documentation rules

- Describe **filesystem truth**, not intended future features.
- Do not pin model/provider names in shared AWF guidance.
- Do not publish unverified performance or automation claims.
- Use logical commands from `.awf/manifest.json` when available.
- Describe optional integrations as optional.
- Run `npm run wiki:lint` after changing wiki/index links.
