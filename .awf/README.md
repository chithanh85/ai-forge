# AWF Native Configuration

`.awf/manifest.json` is the canonical project-local configuration generated by `node scripts/awf/init.mjs`.

Rules:

- AWF core owns policies, workflow contracts, and capability requirements.
- Client adapters (Codex, Gemini/Antigravity, Claude) translate those requirements into native client configuration.
- Actual model selection remains client/user-owned; AWF must not pin vendor model names in core workflows.
- Optional integrations must degrade gracefully when unavailable.
- Generated/runtime state must not be treated as template history.
